Getting started with ComponentHub

ComponentHub is the technical memory of your workshop: every component, module, tool or consumable has a record with its stock, location, documentation and projects using it.

Sections (left sidebar)

  • Inventory - your components, modules, tools and consumables. Global search and filters; open a record to view or edit all its fields, documents and stock movements. Right-click a row: duplicate, stock +1 / −1, change location…
  • Categories - the list of component categories.
  • Locations - your storage locations, organized hierarchically (Workshop > Cabinet > Drawer...).
  • Projects - each project and its bill of materials; the application calculates missing components.
  • Reference data - standardized lists (types, manufacturers, suppliers, packages...) for consistent data entry.
  • Import/Export - CSV import/export by table and complete backup/restore in a .tar archive.
  • Settings - light/dark theme and data folder.

Keyboard shortcuts

  • Ctrl+1 to Ctrl+7 - jump directly to a section.
  • Ctrl+N / Ctrl+F - new record / search (Inventory).
  • Enter, Delete, + and − - edit, delete, adjust the stock of the row.
  • F1 - this help.
  • Ctrl+Q - quit.

Where is my data?

Your data is stored in an SQLite database in your personal data folder (menu File → Open data folder; the path is also shown at the bottom of the window). Remember to make a .tar backup (Import/Export section): it contains the entire workshop in one file, ready to store safely and restore whenever needed.
